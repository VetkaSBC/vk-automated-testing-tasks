Написание автотестов с паттернами проектирования автотестов

Усложняем проект за счет использования паттернов
Добавляем 1-2 теста или переписываем имеющееся, в коде должны быть паттерны:
Базовые (активно используем):
Page object
Page element/Decorator/Wrapper
Loadable component
Chain of invocations
Value object

Дополнительные (минимум один должен быть использован)
Data provider
Factory
Data registry
Promise
и оставшиеся
